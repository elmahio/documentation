# How many organizations can I create?

There is no limit on the number of organizations you can create on elmah.io. You can create as many organizations as you need.

Each organization requires its own subscription. The elmah.io subscription is attached to the organization, not to the user. This means that while a new organization can use the free trial period, once the trial ends, that specific organization needs its own paid plan to continue being used. Creating more organizations does not extend or share a single subscription across them; a separate subscription must be purchased per organization.

Logs cannot be moved between organizations. A log created inside one organization stays inside that organization. If you need messages from one organization available in another, you must configure the applications sending those messages to log to a log in the target organization instead; existing logged messages cannot be transferred or merged across organizations.
